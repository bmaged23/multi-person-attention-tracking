# Optional historical research-source tools

These tools support older experiments, not the current COCO/AMI release gate.
Their source footage remains under ignored `input/`; generated output stays under
ignored `output/`. They are kept as research provenance, not downloaded by setup.

| Tool | Source / role |
| --- | --- |
| `inspect_tvhi_clips.py` | Inspect already downloaded TVHI clips for multiple visible faces |
| `prepare_tvhi_videos.py` | Oxford TVHI research footage |
| `prepare_classroom_research_videos.py` | CDED-7 restricted classroom experiments |
| `prepare_rwead_clips.py` | Previously used CC-BY RWEAD audience clips |

See [source terms](../../../docs/THIRD_PARTY.md),
[TVHI notes](../../../docs/TEST_DATA.md) and
[historical classroom notes](../../../docs/CLASSROOM_TESTS.md).
For current evaluation, use the [evaluation README](../../../docs/evaluation/README.md).
